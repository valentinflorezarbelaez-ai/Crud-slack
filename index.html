          Entregable Final · Sustentación Técnica y Funcional
          
    
            Reto Práctico Final: Organiza Tareas con IA
          
    
          
    
            Documentación ejecutiva completa de los 5 puntos requeridos para la presentación y guía
            estructurada para las 5 preguntas de conversación con Luis Soto.
          
    
        
    

        
    
          
    
            01
            
    La solución propuesta
    
            
    
              Construimos TaskFlow AI, un espacio de trabajo inteligente que convierte solicitudes no
              estructuradas recibidas por correo electrónico, Slack, Microsoft Teams o WhatsApp en un
              plan operativo claro, priorizado y editable (CRUD completo).
            
    
            
      
              
    • Problema que resuelve: Evita que tareas clave ocultas dentro de párrafos largos se olviden, elimina la parálisis por no saber qué atender primero y previene malentendidos por fechas ambiguas.
      • 
              
    • Diferenciador clave (Anti-Alucinación): En lugar de inventar fechas límite cuando el remitente no las menciona, distingue entre Fecha Confirmada, Referencia Parcial (ej. «para el viernes» sin hora) e Información Faltante, generando además un mensaje listo para pedir aclaración al remitente.
      • 
            
    
          
    

          
    
            02
            
    Las herramientas utilizadas y por qué
    
            
      
              
    • Google Gemini 3.8 Flash (Interactions API con JSON Schema estricto): Elegido por su baja latencia, excelente comprensión del español corporativo y soporte nativo de salidas estructuradas tipadas.
      • 
              
    • Motor Neuro-Simbólico & Verificador Layer-0 (JavaScript/ESM puro sin dependencias externas): Audita cada salida de la IA contra el texto original para garantizar 0 fechas inventadas y actúa como Circuit Breaker instantáneo (< 2 ms) si la red o la API externa fallan.
      • 
              
    • Arquitectura Hexagonal + Vercel Fluid Compute (Node.js 24): Aísla la clave de API en el servidor (cero secretos expuestos en el navegador) y ofrece despliegue HTTPS inmediato con encabezados de seguridad OWASP.
      • 
              
    • Exportador Nativo CSV (SharePoint Lists / Planner) y Markdown (Slack/Teams): Conecta el resultado directamente con las plataformas donde trabajan los equipos reales.
      • 
            
    
          
    

          
    
            03
            
    El funcionamiento paso a paso
    
            
      
              
    1. Ingesta: El usuario pega la solicitud de correo/chat (o elige un caso de prueba), selecciona el canal y la fecha de referencia.
      2. 
              
    2. Extracción y Orden Lógico: La IA separa las actividades compuestas y las ordena por precedencia real (ej. 1° Revisar resultados del mes ➔ 2° Actualizar presentación ➔ 3° Enviar agenda antes de la reunión ➔ 4° Reunión del viernes).
      3. 
              
    3. Auditoría Anti-Alucinación: El verificador comprueba que cada tarea tenga cita textual real (sourceQuote) y revoca cualquier fecha que no tenga sustento en el mensaje.
      4. 
              
    4. Gestión Visual y CRUD: El equipo visualiza métricas, alterna entre Lista Visual, Tabla Ejecutiva y Kanban, completa las fechas faltantes con un clic y exporta a SharePoint Lists o Slack.
      5. 
            
    
          
    

          
    
            04
            
    Las dificultades encontradas y cómo las resolvimos
    
            
      
              
    • Tendencia de los LLMs a «adivinar» fechas: Los modelos generativos suelen inventar horas o fechas intermedias para parecer útiles. Solución: Diseñamos un estado explícito MISSING_INFO / PARTIAL_ANCHOR en el esquema y un verificador determinista post-IA que bloquea fechas sin ancla léxica.
      • 
              
    • Prioridades implícitas por dependencia: En el ejemplo del viernes, ninguna tarea dice la palabra «urgente», pero revisar resultados bloquea actualizar la presentación. Solución: Modelamos fases de dependencia lógica (insumo ➔ entregable ➔ envío previo ➔ evento hito).
      • 
              
    • Disponibilidad garantizada durante evaluaciones en vivo: Depender de una sola API externa puede fallar por cuota o red. Solución: Implementamos un patrón Circuit Breaker con motor NLP determinista local de respaldo.
      • 
            
    
          
    

          
    
            05
            
    Las oportunidades de mejora (Roadmap)
    
            
    
              
    
                
    Integración Directa Microsoft 365 & SharePoint
    
                
    Conectar mediante Microsoft Graph API y Power Automate para crear ítems automáticamente en SharePoint Lists, Microsoft Planner o To Do al marcar un correo en Outlook o Teams.
    
              
    
              
    
                
    Bot Nativo Bidireccional en Slack / Teams
    
                
    Incorporar Slash Commands y Webhooks firmados (HMAC) para transformar un hilo de chat en tareas con un solo emoji (⚡) y publicar botones interactivos de confirmación.
    
              
    
              
    
                
    Memoria de Equipo y Carga de Trabajo
    
                
    Sugerir responsables automáticamente según el rol histórico de cada miembro del equipo y alertar sobrecarga de tareas en una misma semana.
    
              
    
            
    
          
    
        
    

        
        
    
          
    
            Preguntas de Conversación para la Presentación
          
    

          
    
            
    
              1. ¿Por qué elegiste esta idea y estas herramientas?
              
    
                
    
                  Elegí construir un espacio de triaje interactivo con CRUD y exportación porque una tabla estática se queda corta apenas llega la realidad del trabajo: alguien confirma la fecha que faltaba o cambia el estado de una tarea. Combiné Gemini 3.8 Flash (para comprensión semántica con JSON Schema estricto) con un verificador determinista sin dependencias desplegado en Vercel para lograr velocidad, seguridad de credenciales en servidor y cero fricción de uso desde cualquier navegador o celular.
                
    
              
    
            
    

            
    
              2. ¿Qué fue lo más difícil y cómo lo resolviste?
              
    
                
    
                  Lo más retador fue lograr el equilibrio exacto en las fechas relativas: en «preparar la reunión para el viernes y enviar la agenda antes de la reunión», «el viernes» sí es un ancla real para la reunión, pero las tareas previas no tienen día ni hora exacta. Lo resolví separando el estado temporal en tres niveles (Confirmada, Referencia Parcial e Información Faltante) y añadiendo una guardia determinista que impide que la IA invente fechas intermedias.
                
    
              
    
            
    

            
    
              3. ¿Cómo comprobarías que las tareas identificadas por la IA son correctas?
              
    
                
    
                  Implementé tres mecanismos verificables en tiempo real visibles en la tarjeta de auditoría de la aplicación:
                
    
                
      
                  
    • Sustento por Cita Textual (Quote Grounding): Cada tarea exige el campo sourceQuote y el sistema verifica algorítmicamente que esos términos existan realmente en el mensaje original.
      • 
                  
    • Auditoría Anti-Alucinación Temporal y de Responsables: Si el modelo emite una fecha ISO o un nombre propio que no tiene respaldo léxico en el texto fuente, el verificador la revoca automáticamente y la marca como información faltante.
      • 
                  
    • Suite Automatizada BDD y Revisión Humana (Human-in-the-Loop): Contamos con pruebas unitarias automatizadas (node:test) con casos borde (0 fechas, múltiples cláusulas, inyección) y edición CRUD inmediata para que el usuario valide antes de exportar.
      • 
                
    
              
    
            
    

            
    
              4. ¿Qué mejorarías si tuvieras una hora adicional?
              
    
                
    
                  En una hora adicional conectaría un Webhook entrante hacia Power Automate / SharePoint Lists (o un Incoming Webhook de Slack/Teams) con un botón «Publicar Plan en Canal / Lista», de modo que además de descargar el CSV compatible con SharePoint, las tareas queden creadas directamente en la lista compartida del equipo con un clic.
                
    
              
    
            
    

            
    
              5. ¿Cómo convertirías esta demostración en una solución que otras personas pudieran utilizar?
              
    
                
    
                  En tres pasos incrementales: (1) Autenticación corporativa SSO (Microsoft Entra ID / Google Workspace) para separar tableros por equipo; (2) Persistencia compartida en base de datos transaccional (PostgreSQL / SharePoint Lists backend) con control de permisos por rol; y (3) Conectores omnicanal pasivos (add-in de Outlook, app de Teams/Slack) para que el usuario ni siquiera tenga que copiar y pegar el mensaje.
